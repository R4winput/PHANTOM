# Security policy

PHANTOM is experimental software and is not currently suitable for protecting sensitive communications.

## Reporting a vulnerability

Please do not open a public issue containing an exploitable vulnerability. Use GitHub's private vulnerability reporting for this repository when available. Include affected revision, impact, reproduction steps, and any relevant logs or packet captures with secrets removed.

Do not include real users' messages, private keys, invitation tokens, or identifying network data in a report. We will acknowledge reports and coordinate a fix before public disclosure where practical.

## Scope and guarantees

The current foundation has no network protocol and therefore has no deployed security guarantees. Future claims must be tied to a documented threat model and reproducible tests. In particular, end-to-end encryption does not conceal traffic metadata, stop recipients from copying content, or guarantee physical memory erasure.
